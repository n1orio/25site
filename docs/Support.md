# Поддержка и счётчик

## Ссылки на поддержку

Массив `donations` в `config.ts`, рендерится компонентом `Donations.vue` в
конце вкладки «Связь».

```ts
export const donations: Donation[] = [
  {
    title: "50 ₽",
    note: "на кофе",
    url: "https://pay.lava.ru/w/.../link",
  },
  {
    title: "250 ₽",
    note: "поддержать проект",
    url: "https://pay.lava.ru/w/.../link",
    featured: true,      // кнопка выделяется заливкой
  },
]
```

Поле `featured` необязательно — без него карточка выглядит спокойнее. Хочешь
добавить сумму: допиши объект в массив, компонент перерисуется сам.

## Счётчик посетителей

В футере показывает, сколько уникальных посетителей было за 30 дней.

### Как считается

`server/middleware/visitors.ts` считает **только HTML-страницы**: запросы к
`/api/*`, `/_nuxt/*` и всё, что заканчивается расширением файла, отсекаются на
входе.

Идентификатор посетителя — не IP, а `sha256(ip + user-agent + accept-language)`,
обрезанный до 16 символов. Сырые адреса не покидают сервер и не копятся в
хранилище. За обратным прокси реального адреса может не быть — тогда все
считаются одним посетителем, но это лучше, чем публиковать адреса.

Повторный визит в течение 30 минут вообще не трогает хранилище, а записи старше
180 дней вычищаются раз в час, чтобы карта не росла бесконечно.

### Где хранится

Nitro storage, драйвер `fs`, путь **`/data/kv`** — он совпадает с точкой
монтирования тома `site_data` в `docker-compose.yml`.

⚠️ **Путь зафиксирован в `nuxt.config.ts` намеренно.** Конфиг читается на этапе
*сборки* образа, поэтому полагаться на переменную окружения нельзя: на сборке её
ещё нет, база получается `./.data/kv` внутри образа, и данные пишутся мимо тома.
Счётчик переживает рестарт контейнера, но обнуляется при каждом пересоздании —
именно это и случилось, пока путь не зафиксировали.

### Проверка

```bash
curl -s https://твой-сайт.ru/api/visitors
# {"today":3,"month":27,"total":41}
```

Файлы лежат в томе:

```bash
find /var/lib/docker/volumes/<project>_site_data/_data -type f
```

### Если хочешь сбросить счётчик

```bash
docker exec 25site-site-1 rm -rf /data/kv/visitors
```

### Что счётчик не делает

Не считает повторные просмотры внутри получаса и не различает людей за одним
NAT — для личного сайта это нормально. Точной аналитики без внешнего сервиса
(Яндекс.Метрика или Plausible) здесь не получится: счётчик хранит только хеши и
ничего не отдаёт наружу.
