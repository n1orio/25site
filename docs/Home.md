# Форк: как сделать сайт своим

Полное руководство по замене контента, настройке API и кастомизации.

```bash
git clone <форк>
cd site
bun install
bun dev
```

Открой `http://localhost:3000`.

**Все текстовые данные лежат в одном файле — `config.ts`.** После его правки перезапуск не нужен — hot-reload сам подхватит изменения.

## Автоматические блоки

Часть содержимого подтягивается сама и в `config.ts` не лежит:

- **вкладка Deadlock** — ранг, статистика, герои с ddlk.bio;
- **метрики проектов и календарь вкладов** — с GitHub;
- **метрики модов** — с Modrinth;
- **локальное время и погода** — Open-Meteo, ключ не нужен.

Всё это требует только ключей в `.env` (см. [Деплой](Deploy)).
