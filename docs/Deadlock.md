# Вкладка Deadlock

Страница `pages/deadlock.vue` + компонент `components/DeadlockStats.vue`.
Данные берутся с сайта [ddlk.bio](https://ddlk.bio) автоматически — руками
ничего вводить не нужно, всё тянется при заходе на вкладку.

Свой профиль: https://ddlk.bio/profile/niorio

## Что показывается

| Блок | Содержимое |
|---|---|
| Ранг | Эмблема с сайта, название, очки, прогресс до следующего |
| Активность | Хитмап 12 недель, часы в игре, матчей всего и в среднем в день, самый плотный день |
| Ключевые показатели | KDA, accuracy, хедшоты, матчи, винрейт, счёт, среднее место, подозрения |
| Ранкед против анранкеда | Разбивка по режимам, сумма очков, лучший плюс и худший минус |
| Экономика и серии | Средний и максимальный нетворс, длительность матча, серия побед |
| Герои | До 8 героев: матчи, винрейт, средний KDA и киллы, полоса прогресса |
| Любимые улучшения | Предметы с иконками, тиром (цифра справа) и типом в подсказке |
| Последние матчи | Герой, режим, ранг матча, KDA, нетворс, длительность, дельта, место `n/12` |

## Эндпоинты ddlk.bio

Четыре запроса, все параллельно, обёрнуты в `cachedFetch` на 3 минуты:

```ts
const BASE = "https://ddlk.bio/api/profile/niorio"

$fetch(`${BASE}/mmr`)                        // ранг и очки
$fetch(`${BASE}/matches?limit=50`)           // матчи (максимум 50!)
$fetch(`${BASE}/stats`)                      // kda, accuracy, хедшоты, риск
$fetch(`${BASE}/favorites?limit=8`)          // предметы
```

Один ответ `/matches` весит около 160 КБ, поэтому на сервере он
превращается в узкий объект: страница получает пару килобайт вместо
всей истории. Кэш 3 минуты — при нём запросы tопятся и страница не
тормозит при переключении вкладок.

## Что берём из ответов

- `matches.activity` — дни окна (у ddlk.bio это примерно три месяца):
  матчи, победы и секунды за день. Отсюда хитмап, часы в игре и
  среднее число матчей в день.
- `matches.recent_matches[].performance` — `place` и `participants`.
  Заполнено не во всех режимах, поэтому среднее место считаем только
  когда размеченных матчей хотя бы три.
- `stats` — кроме kda/accuracy/headshot_rate приходят
  `cheater_probability_percent` и `confidence` («уверенность оценки»).
- `favorites.favorite_items[]` — `item_type` и `item_tier` для подписи.

`limit=100` уже не работает (ответ 142 байта), максимум — 50 матчей.

## Разбор режимов

Тот же алгоритм, что на ddlk.bio:

```ts
const modeOf = (m) => {
  if (m.game_mode === 4) return "street-brawl"   // Улица
  if (m.match_mode !== 4) return "standard"      // Стандарт
  return "ranked"                                // Ранкед
}
```

## Эмблема ранга

Собирается из индексов ответа `/mmr`: `division` — индекс ранга в списке
(4 = Sentinel), `division_tier` — подранг (1..6).

```ts
`https://ddlk.bio/assets/ranks/${division}_large_subrank${tier}_webp.webp`
```

Если подранга нет, файл называется `${division}_large_webp.webp`.

## Свой профиль

Поменяй `LOGIN` в начале `server/api/deadlock.ts` и `BASE` — на свой. Если у
тебя нет аккаунта на ddlk.bio, блок просто не отрисуется.
