# Погода и время

Блок `components/LocalStatus.vue` в сайдбаре: местное время, дата, текущая
погода и ветер. Всё подтягивается само.

## Настройка

Всё в одном объекте в `config.ts`:

```ts
export const location = {
  city: "Армавир",
  timezone: "Europe/Moscow",   // IANA-таймзона для Intl
  lat: 44.9386,               // координаты для Open-Meteo
  lon: 40.1003,
}
```

Поменял город — поменяй всё три поля.

## Погода

Источник — [Open-Meteo](https://open-meteo.com/). **Ключ не нужен**, только
координаты. Кэш 15 минут — погода меняется быстрее статистики.

Запрашиваются только текущие значения, без прогноза:

```
current=temperature_2m,apparent_temperature,weather_code,is_day,wind_speed_10m
```

WMO-коды нормализуются в свои состояния, для каждого — подпись на русском и
иконка:

| Коды | Состояние | Иконка |
|---|---|---|
| 0 | Ясно | солнце / луна |
| 1–2 | Преимущественно ясно, переменная облачность | cloud-sun / cloud-moon |
| 3 | Пасмурно | cloud |
| 45, 48 | Туман | cloud-fog |
| 51–57 | Морось | cloud-drizzle |
| 61–67 | Дождь | cloud-rain |
| 71–77, 85, 86 | Снег | cloud-snow |
| 80–82 | Ливень | cloud-rain-wind |
| 95+ | Гроза | cloud-lightning |

## Время

Часы тикают **только на клиенте**, раз в 15 секунд. На сервере рендерится
заглушка `--:--`, иначе при гидрации значение в разметке разошлось бы с
клиентским и Vue выдал бы предупреждение.

Иконка слева меняется по местному часу: до 6 и после 20 — луна, иначе солнце.
Час читается именно в городской таймзоне, а не в системной.

## Копирование ссылок

Композабл `useCopy` — общий, переиспользуется везде. Сейчас используется на
соцсетях вкладки «Соцсети»: кнопка копирует адрес и на 1.6 секунды
подтверждает это иконкой-галочкой и подписью под сеткой.

`navigator.clipboard` требует защищённого контекста (https или localhost),
поэтому есть запасной путь через `execCommand` — иначе по http копирование
молча не работало бы.
