# Проекты

Все данные — в файле `config.ts`, массив `projects`.

```ts
{
  icon: "lucide:bot",                      // иконка
  title: "Название проекта",               // название
  desc: "Короткое описание",               // описание
  tags: ["Vue", "Tailwind"],               // массив тегов
  archived: true,                          // перенести в секцию «Архив» внизу
  noHover: false,                          // отключить ховер-подъём (необязательно)
  links: [                                // ссылки (может быть пустым)
    { label: "GitHub", icon: "mdi:github", url: "https://..." },
  ],
}
```

## Архив

Проекты с `archived: true` собираются в отдельную секцию «Архив» внизу
страницы — плоскими строками вместо карточек. Так они выглядят спокойнее и не
показывают статистику GitHub (сервер их пропускает).

## Статистика GitHub

Карточки с ссылкой на github.com автоматически получают звёзды, число
коммитов, скачивания релизов и дату последнего пуша. Ничего настраивать не
нужно — репозиторий определяется по ссылке. Подробности в
[Статистика GitHub](Github).

## Календарь вкладов

Внизу страницыProjects показан календарь вкладов с GitHub — тоже
автоматически.
