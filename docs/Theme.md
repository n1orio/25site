# Цвета и тема

Файл: `composables/useSecretTheme.ts`

## Как это устроено

Цветовые токены (`--accent-surface`, `--accent-contrast`, `--accent-on-bg`)
**нельзя задавать вручную** — они вычисляются. Пользователь выбирает только
акцент, а полярность текста задаёт тема:

- **тёмная тема** → текст всегда светлый, акцент затемняется;
- **светлая тема** → текст всегда тёмный, акцент осветляется.

Акцент подтягивается пошагово, пока контраст не достигнет `MIN_CR = 5.0`.
Оттенок при этом сохраняется. Проверено на 7 акцентах × 2 темы — все
комбинации держат ≥ 5:1.

Логика полностью в `accentPair` и `accentOnBg` — если хочешь поменять порог
контраста, правь `MIN_CR`.

## Акцентный цвет

```ts
const accentColor = useLocalStorage("nio-accent-color", "#6366f1");
//                                                         ↑ значение по умолчанию
```

Выбирается палитрой в навбаре (вторая кнопка) или собственным цветом.

## Градиенты-пресеты

```ts
const gradientPresets = [
  { id: "ruby",   name: "Рубин",  colors: ["#e53935", "#e35d5b"] },
  { id: "sunset", name: "Закат",  colors: ["#f46b45", "#eea849"] },
  { id: "forest", name: "Лес",    colors: ["#2ECC71", "#145A32"] },
  // ...
]
```

Добавляй свои или удаляй ненужные — хоть все, хоть ни одного.

## Светлая и тёмная тема

Используется `useDark()` из VueUse: подхватывает системную настройку при
первом заходе. Кнопка переключения — солнце/луна в навбаре, клик по ней
переключает тему.

## Круговая анимация переключения

Файл: `composables/useThemeCircle.ts`. Старая тема отступает от краёв к точке
клика, открывая новую.

- Основной путь — **View Transitions**: анимируется снимок старой темы
  (`::view-transition-old(root)`), поэтому раскрывается настоящая новая тема
  с её содержимым, а не плоская заливка. Без этого мигает в конце.
- Если API недоступно — слой `#theme-circle`, залитый цветом **текущего** фона,
  поэтому стык не виден.
- Уважается `prefers-reduced-motion`: при включённой настройке переключение
  мгновенное.
- Смена акцента через палитру идёт тем же эффектом.

Тот же эффект используется для смены акцентного цвета — раньше она была
мгновенной и выбивалась из общего стиля.

## Ключи в localStorage

| Ключ | Что хранит |
|---|---|
| `nio-theme-mode` | `single` или `gradient` |
| `nio-accent-color` | выбранный акцент |
| `nio-active-gradient` | цвета активного градиента |

Плюс служебный ключ VueUse для темы (`vueuse-color-scheme`).
