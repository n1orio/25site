# Цвета и тема

Файл: `composables/useSecretTheme.ts`

## Как это устроено

Цветовые токены (`--accent-surface`, `--accent-contrast`, `--accent-on-bg`)
**нельзя задавать вручную** — они вычисляются. Пользователь выбирает только
акцент, а полярность текста задаёт тема:

- **тёмная тема** → текст всегда светлый, акцент затемняется;
- **светлая тема** → текст всегда тёмный, акцент осветляется.

Акцент подтягивается пошагово, пока контраст не достигнет `MIN_CR = 5.0`.
Оттенок при этом сохраняется. Проверено на 7 акцентах × 2 темы — все
комбинации держат ≥ 5:1.

Логика полностью в `accentPair` и `accentOnBg` — если хочешь поменять порог
контраста, правь `MIN_CR`.

## Тема по умолчанию

Новые посетители приходят на градиент **«Океан»**:

```ts
const DEFAULT_PRESET = "ocean";   // id пресета

const themeMode = useLocalStorage("nio-theme-mode", "gradient");
const accentColor = useLocalStorage("nio-accent-color", defaultColors()[0]!);
const activeGradient = useLocalStorage("nio-active-gradient", defaultColors());
```

Цвета берутся из самого пресета по его `id`, а не продублированы рядом —
поменял палитру «Океана», дефолт поедет вместе с ней.

Поменять дефолт: укажи другой id в `DEFAULT_PRESET`.

⚠️ Значения хранятся в localStorage, поэтому смена дефолта влияет только на
тех, кто зашёл впервые. У кого выбор уже сохранён — останется его тема.
Сбросить вручную: в консоли `localStorage.clear()` и перезагрузка.

## Тема «Дедлок» — слой оформления

Остальные темы меняют только цвет. «Дедлок» переделывает интерфейс целиком:
формы, тени, шрифты, фон. Оформление скопировано с `/home/nio/mistraly-site`.

| Что | Значение |
|---|---|
| Файл слоя | `assets/css/deadlock.css` |
| Подключение | `nuxt.config.ts` → `css`, после `main.css` |
| Включение | атрибут `data-deadlock` на `.theme-wrapper` (`app.vue`) |
| Флажок | `isDeadlock` в `useSecretTheme` |
| Палитра | фон `#0C0C0C`, карточки `#292820`, акцент `#DD6638` |
| Шрифт заголовков | TF2 Build, локально `public/fonts/tf2build.woff2` |
| Шрифт абзацев | Podkova с Google Fonts, лениво |

### Почему палитра в composable, а формы в CSS

`--accent`, `--accent-surface`, `--accent-contrast`, `--accent-on-bg`,
`--bg-1`, `--bg-2` приходят в разметку **инлайном** (`:style` в `app.vue`),
а инлайн бьёт любой селектор — из CSS их не перебить. Их задаёт
`useSecretTheme` (константа `DEADLOCK`).

Остальные токены (`--bg-primary`, `--text-*`, `--bg-surface*`, `--radius-*`,
`--font-*`) переопределяются каскадом, поэтому живут в `deadlock.css`.

### Как включён и почему не течёт на другие темы

Тема опознаётся по паре цветов пресета — `nio-active-gradient` должен
равняться `DEADLOCK.colors`. Всё оформление лежит под `[data-deadlock]`,
поэтому у остальных пресетов не применяется ни одно правило.

### Шрифты

- **TF2 Build** (`public/fonts/tf2build.woff2`, 18 КБ) — заголовки, вкладки,
  подписи, цифры. Гарнитура от Valve, разработка Andrea Wicklund; файл взят с
  публичной страницы предпросмотра fonts-online.ru (отдаётся анонимно) и
  сконвертирован из ttf в woff2. `@font-face` объявлен прямо в `deadlock.css`,
  поэтому качается он только когда тема включена.
- **Podkova** — абзацы. Тянутся с Google Fonts только когда тема включена,
  через `composables/useDeadlockFonts.ts` (реактивный `useHead`).

TF2 Build шире, чем Fira Sans Condensed, которым он заменил служебный текст:
в слое уменьшены кегль `.ds-meta` и межбуквенный интервал, иначе подписи в
узких местах («АРМАНИЯ» в блоке часов) уходили в многоточие.

### Что переделывает слой

- карточки: `filter: drop-shadow(8px 8px 0 …)`, выезд `(-3px,-4px)` на hover,
  свой `clip-path` у каждой в ряду, точечный растр (Ben-Day) на hover,
  оранжевая черта внизу, растягивающаяся при наведении;
- навигация: отдельные плитки со срезом и тенью, выезд вверх на 7px,
  активная — заливка акцентом;
- типографика: заголовки Russo One в верхнем регистре, текст Podkova 700,
  цифры Fira Sans Condensed 900;
- фон ровный, без цветных пятен; волны-разделители скрыты;
- своя светлая версия (в `html:not(.dark) [data-deadlock]`), иначе
  переключатель светлая/тёмная выглядел бы сломанным.

### Грабли, на которые уже наступили

- `.ds-card` в слое ставит `position: relative` — из-за этого выпадашка
  палитры (`ds-pop`, `absolute`) выпадала из потока и растягивала навбар.
  Поэтому у `.ds-pop` в слое явно прописан `position: absolute`.
- navbar — первый ребёнок `<nav>`, поэтому попадал под правила среза для
  карточек (`:nth-child`) и обрезал выпадашку палитры по своим границам:
  кнопка нажималась, а меню было не видно. Перебито правилом
  `[data-deadlock] .ds-card.nav-shell { clip-path: none }`.
- на телефоне сдвиг вкладок вверх (`transform`) поднимал их над
  соседями, и вкладки накрывали кнопки темы — клик уходил в ссылку.
  В `@media (max-width: 640px)` сдвиг отключён, горизонтальная прокрутка
  возвращена;
- пять вкладок на телефоне не влезают (356 КБ в окне 269), поэтому
  список прокручивается. Подсказки о прокрутке в теме тоже нужны: без
  них список выглядит оборванным. Их цвет задан классами
  `.nav-fade-left/right` (в `app.vue`), а не инлайном — иначе «Дедлок»
  не смог бы переопределить его под свой фон.
- Вкладки навигации вылезают на 7px вверх, поэтому `.nav-window` и
  `.nav-track` в слое получают `overflow: visible; height: auto` — иначе
  контейнер срезал подписи («Топ Аниме»).
- Выпадашка палитры нарисована двумя слоями (непрозрачная подложка +
  полупрозрачный верхний): одним `--bg-surface-elevated` сквозь неё
  просвечивали карточки страницы.

## Тема не переживала перезагрузку

localStorage серверу недоступен, поэтому SSR всегда отдаёт дефолтную тему, а
Vue при гидрации не патчит инлайновые стили и `data-`-атрибуты корневого
элемента — выбранная тема слетала до первого перерисовывания.

Лечится в двух местах:

1. `useSecretTheme` синхронизирует refs с localStorage на клиенте
   (`import.meta.client`), до первого рендера;
2. `app.vue` проставляет CSS-переменные и `data-deadlock` прямо в DOM
   (`applyThemeToDom`) — на случай, если Vue всё же не дотронется до
   корневого элемента.

Проверка: выбрать тему, перезагрузить страницу — тема и слой оформления
остаются, переключатель светлая/тёмная работает.

Отсюда же вылез вторая половина бага — **атрибуты**. Vue при гидрации их
тоже не патчит, поэтому подпись и иконка у тумблера оставались от сервера:
в тёмной теме кнопка с самого начала обещала «переключить на тёмную».
Лечится флагом гидрации в `Navigation.vue`:

```ts
const hydrated = ref(false)
onMounted(() => { hydrated.value = true })
const isDarkNow = computed(() => hydrated.value && isDark.value)
```

Флаг нужен, чтобы SSR и первый клиентский рендер совпали (иначе будет
расхождение), а после монтирования компонент перерисовывается и Vue
обновляет `aria-label` с иконкой.

Заодно `useDark()` теперь один на всё приложение (`useAppDark` в
`useSecretTheme`): при каждом вызове он отдаёт свой ref, а внутри вкладки
эти ref'ы не синхронизируются. На сервере ref остаётся локальным, чтобы
состояние не утекало между запросами.

## Светлая и тёмная тема

Используется `useDark()` из VueUse: подхватывает системную настройку при
первом заходе. Кнопка переключения — солнце/луна в навбаре, клик по ней
переключает тему.

## Круговая анимация переключения

Файл: `composables/useThemeCircle.ts`. Старая тема отступает от краёв к точке
клика, открывая новую.

- Основной путь — **View Transitions**: анимируется снимок старой темы
  (`::view-transition-old(root)`), поэтому раскрывается настоящая новая тема
  с её содержимым, а не плоская заливка. Без этого мигает в конце.
- Если API недоступно — слой `#theme-circle`, залитый цветом **текущего** фона,
  поэтому стык не виден.
- Уважается `prefers-reduced-motion`: при включённой настройке переключение
  мгновенное.
- Смена акцента через палитру идёт тем же эффектом.

Тот же эффект используется для смены акцентного цвета — раньше она была
мгновенной и выбивалась из общего стиля.

## Ключи в localStorage

| Ключ | Что хранит |
|---|---|
| `nio-theme-mode` | `single` или `gradient` |
| `nio-accent-color` | выбранный акцент (дефолт — первый цвет «Океана») |
| `nio-active-gradient` | цвета активного градиента |

Плюс служебный ключ VueUse для темы (`vueuse-color-scheme`).
