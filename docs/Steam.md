# Steam статус

Файл: `server/api/steam.ts`

Нужен API-ключ Steam: https://steamcommunity.com/dev/apikey

Создай `.env` в корне:

```env
STEAM_API_KEY=твой_ключ_здесь
STEAM_ID=твой_steam_id
```

**Как узнать Steam ID**: открой профиль в браузере → цифры в адресной строке. Если там имя — используй https://steamid.io.
