# Сетап

Все данные — в файле `config.ts`, два массива:

- `workstationItems` — основное железо
- `baseItems` — дополнительно

```ts
{
  name: "Телефон",                        // название
  value: "iPhone 16 Pro",                 // значение
  comment: "Дермоед",                     // тултип (необязательно)
  link: "https://...",                    // ссылка (необязательно)
}
```
