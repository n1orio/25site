# Сетап

Файл: `pages/uses.vue`

Два массива:

- `hardware` — основное железо
- `extras` — дополнительно (периферия, софт)

```js
{
  name: "Процессор",
  desc: "AMD Ryzen 5 5600X",    // опционально
  url: "https://amd.com/...",    // опционально — ссылка
  note: "Крутой камень",         // опционально — тултип
}
```
