# Соцсети

Файл: `pages/index.vue`

Массив `socials`:

```js
{
  name: "Telegram",                              // название
  desc: "Мой личный канал",                      // описание
  icon: "ic:baseline-telegram",                  // иконка
  url: "https://t.me/niori0",                    // ссылка
  color: "#2AABEE",                              // цвет иконки
}
```

**Иконки**: открой [icones.js.org](https://icones.js.org), формат `collection:name`.  
Популярные коллекции: `lucide`, `simple-icons`, `ic`, `mdi`.

Удали мои ссылки, добавь свои. Можно менять порядок.
