# Дизайн-система

Стилизация вынесена в глобальный `<style>` в `app.vue` (не в Tailwind-утилиты),
чтобы токены применялись ко всем компонентам без импортов.

## Токены

Все цвета — только переменные. Хардкода в вёрстке нет.

| Токен | Назначение |
|---|---|
| `--bg-primary` | фон страницы |
| `--bg-surface` | фон карточек и панелей |
| `--bg-surface-elevated` | фон активных и наведённых карточек |
| `--accent` | выбранный акцент (как есть, без коррекции) |
| `--accent-surface` | акцент, пригодный как фон карточки |
| `--accent-contrast` | текст поверх акцентной заливки |
| `--accent-on-bg` | акцент, читаемый на фоне страницы |
| `--text-primary` | заголовки и основной текст |
| `--text-secondary` | описания и метаданные |
| `--border-subtle` | мягкие рамки и разделители |
| `--radius-card` | скругление карточек (20px) |
| `--radius-pill` | скругление «таблетки» (9999px) |

### Три производных оттенка

`--accent-surface`, `--accent-contrast` и `--accent-on-bg` считаются в
`composables/useSecretTheme.ts` — их нельзя задавать вручную.

- **Полярность задаёт тема, а не акцент.** В тёмной теме текст всегда светлый,
  в светлой — всегда тёмный. Акцентная поверхность подтягивается к нужной
  полярности, сохраняя оттенок, пока контраст не достигнет `MIN_CR = 5.0`.
- `--accent-on-bg` идёт в другую сторону: он читаем на фоне страницы (ссылки
  футера, номер ошибки), поэтому в светлой теме акцент уходит в тень.

Проверено на 7 акцентах × 2 темы — все комбинации держат ≥ 5:1.

## Классы

### На акцентной поверхности (внутри `.ds-card`)

| Класс | Что делает |
|---|---|
| `ds-card` | фон `--accent-surface`, без рамок, скругление карточки |
| `ds-card-hover` | подъём на 3px и `brightness(1.12)` |
| `ds-title` | заголовок: Unbounded 800, трекинг −0.03em |
| `ds-body` | текст: Inter, 15px, контраст 94% |
| `ds-meta` | метаданные: моноширинный, uppercase, 11px |
| `ds-num` | нумерация, ещё приглушённее |
| `ds-stat` | крупные числа с табличными цифрами |
| `ds-pill` | «таблетка» для тегов и бейджей |
| `ds-action` | круглая кнопка действия (↗), инвертируется на hover |
| `ds-bar` | полоса прогресса |
| `ds-wave` | волна-разделитель |

### На фоне страницы (вне карточек)

`on-bg-title`, `on-bg-body`, `on-bg-meta` — те же роли, но цвета от
`--text-primary` / `--text-secondary`. **Важно:** `ds-*` на фоне страницы
невидимы, они рассчитаны на акцентную подложку.

### Служебные

| Класс | Что делает |
|---|---|
| `nav-ctl` | круглая кнопка в навбаре (тема, палитра) |
| `theme-circle` | слой кругового переключения темы |

## Волна-разделитель

`WaveDivider` — не SVG, а CSS-маска с плиткой фиксированного размера:
`--wave-tile: 120px`, `mask-repeat: repeat-x`. Поэтому волна выглядит
одинаково в любом контейнере и не растягивается. Цвет берётся из
`currentColor`, поэтому одинаково красится и на карточке, и на фоне.

## Шрифты

| Роль | Шрифт | Откуда |
|---|---|---|
| Заголовки | Unbounded 400/800 | Google Fonts |
| Основной текст | Inter 100–900 | `public/fonts/`, самохостинг |
| Метаданные | Monaspace Argon 400/700 | `public/fonts/`, самохостинг |

Inter отдаётся двумя сабсетами (latin 47 КБ + cyrillic 18 КБ) с
`unicode-range`, оба в preload. Базовый вес текста — 550.
