# Статистика GitHub

Две независимые фичи на вкладке «Проекты», обе тянут данные с GitHub
автоматически. Кэш — 1 час.

## 1. Метрики в карточках проектов

Файл: `server/api/github.ts`

В каждой карточке с ссылкой на репозиторий появляются: звёзды, точное число
коммитов, суммарные скачивания релизов, дата последнего пуша и полоска состава
по языкам. Плюс сводка по аккаунту в шапке вкладки.

### Как определяется репозиторий

Из ссылки на github.com в `config.ts` — отдельно id прописывать не надо:

```ts
const m = l.url.match(/^https?:\/\/github\.com\/([\w.-]+)\/([\w.-]+?)(?:\.git)?(?:\/|$)/i)
```

Если репозиторий переименован, API сам отдаёт актуальное имя, а карточка
находит его по имени после слэша — переименования обрабатываются молча.

### Как считается число коммитов

GitHub не отдаёт его в списке репозиториев. Запрашиваем одну страницу с
`per_page=1` и читаем последнюю страницу из заголовка `Link`:

```
link: <.../commits?per_page=1&page=251>; rel="last"
```

```ts
const last = link.match(/[?&]page=(\d+)>;\s*rel="last"/)
return last ? Number(last[1]) : null   // 251 коммит
```

### Состав по языкам

`/languages` отдаёт **байты**, а не проценты, — доли считаются от их суммы.
У Mono Launcher так видно, что это фронт (Vue) плюс ядро (Rust) и TypeScript,
а не одна технология.

### Токен

Без токена лимит GitHub — 60 запросов в час, этого хватает впритык. С токеном
стало 5000. Токен fine-grained с доступом «Public repositories (read-only)»:

1. https://github.com/settings/tokens → Generate new token (fine-grained)
2. Public repositories (read-only), expiration 90 дней
3. Положить в `.env`: `NUXT_GITHUB_TOKEN=github_pat_...`

Токен читается в рантайме, поэтому после замены хватит
`docker compose restart site`.

## 2. Календарь вкладов

Файл: `server/api/contributions.ts`, компонент `components/ContributionGraph.vue`.

**Важно и неудобно: официального API для календаря не существует.** Ни REST, ни
GraphQL его не отдают, точные количества вкладов GitHub не публикует нигде.
Доступно только 5 уровней интенсивности в HTML страницы профиля:

```
https://github.com/users/{login}/contributions
```

```html
<td data-date="2026-01-04" data-level="0" ...>
```

Поэтому:

- плитки красятся по уровню 0–4, как на GitHub;
- в поповере — дата и уровень («немного · 9 января 2026»), **а не число**;
- считаются активные дни (уровень > 0) и самая длинная серия.

Это неофициальный парсинг: если GitHub поменяет разметку, эндпоинт вернёт
`null` и блок просто не отрисуется — сайт не сломается.

## Плитки кликабельные

Как на GitHub:

- **наведение** — поповер появляется;
- **клик** — поповер закрепляется, уводишь мышь, а он остаётся (для тача);
- **Escape** — снимает закрепление;
- у выбранной плитки появляется обводка.

Плитки — настоящие `<button>` с `aria-label` вида «9 января 2026: немного»,
так что работают с клавиатуры и для скринридеров.

## Свой аккаунт

Поменяй `LOGIN` в `server/api/github.ts` и `server/api/contributions.ts`.
