# API и кэш

Все внешние данные идут через `server/api/*` и кэшируются в памяти процесса.
Браузер ходит только на свой домен, наружу — только сервер.

## `cachedFetch`

Файл: `server/utils/cache.ts`

```ts
cachedFetch<T>(key: string, ttlMs: number, fetcher: () => Promise<T>): Promise<T>
```

Простейший кэш: `Map` с временем истечения. Нет запроса на вылет — есть
один и тот же ключ. Если эндпоинт падает (лимит, сеть), обёртка возвращает
`null`, и блок на странице просто не рисуется — страница не ломается.

| Эндпоинт | TTL | Ходит куда |
|---|---|---|
| `/api/discord` | 90 с | Lanyard |
| `/api/steam` | 120 с | Steam Web API (4 запроса сразу) |
| `/api/deadlock` | 180 с | ddlk.bio (4 запроса сразу) |
| `/api/github` | 1 ч | GitHub (1 + 3 на проект) |
| `/api/contributions` | 1 ч | HTML-страница GitHub |
| `/api/modrinth` | 1 ч | Modrinth: скачивания и фоллверы |
| `/api/weather` | 15 мин | Open-Meteo (ключ не нужен) |

Кэш живёт в памяти процесса, поэтому после перезапуска контейнера первый
запрос будет холодным.

## Что снаружи видно

| Путь | Ответ |
|---|---|
| `/api/discord` | аватар, имя, активности, статус цвет |
| `/api/steam` | персона, состояние, игра, уровень, часы |
| `/api/deadlock` | ранг, ранкед/анранкед, герои, предметы, матчи |
| `/api/github` | сводка по аккаунту + статистика по проектам |
| `/api/contributions` | календарь вкладов (уровни, без точных чисел) |
| `/api/modrinth` | данные модов: скачивания, фоллверы, лицензия |
| `/api/weather` | текущая погода: температура, состояние, ветер, день/ночь |

## Ограничения внешних API

- **GitHub**: 60 запросов/час без токена, 5000 с `NUXT_GITHUB_TOKEN`.
  Репозиторий переименованный находится по редиректу — работает само.
- **ddlk.bio**: `matches` отдаёт максимум 50 матчей. Вся аналитика по режимам,
  героям и сериям считается по этой выборке, а totals — по всем матчам. В
  интерфейсе это подписано явно («за 50 последних матчей»).
- **Steam**: если ключ невалиден, приходит 403 и срабатывает заглушка.
  Сравнить легко: у настоящих данных есть `personaname`, у мока — «Неизвестно».
- **Календарь вкладов**: официального API не существует, GitHub отдаёт
  только 5 уровней интенсивности, без чисел. Подробнее в
  [Статистика GitHub](Github).

## Переменные окружения

Читаются как `NUXT_*`. Префикс обязателен: без него значение запекается в
образ на этапе сборки Docker и не обновляется без пересборки. Это уже
приводило к багу — ключ Steam менялся в `.env`, а сайт продолжал использовать
старый, зашитый в образ.

```env
NUXT_STEAM_API_KEY=...
NUXT_STEAM_ID=...
NUXT_GITHUB_TOKEN=...
```

После правки достаточно `docker compose restart site` — пересборка не нужна.
