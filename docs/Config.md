# config.ts — настройка содержимого

В этом файле хранятся все текстовые данные сайта. Чтобы изменить контент — правишь только его.

## Что можно менять

| Поле | Тип | Описание |
|---|---|---|
| `logo` | string | Текст логотипа ("nio") |
| `username` | string | Отображаемый юзернейм |
| `bioTitle` | string | Заголовок профиля |
| `bio` | string[] | Абзацы описания |
| `navTabs` | { label, to }[] | Табы навигации |
| `socials` | Social[] | Список соцсетей |
| `projects` | Project[] | Карточки проектов |
| `workstationItems` | WorkstationItem[] | Железо |
| `baseItems` | WorkstationItem[] | Дополнительно |
| `topAnime` | Anime[] | Рейтинг аниме |
| `animeDisclaimer` | string | Текст над топом |

## Формат

См. типы в начале файла — у каждого поля есть интерфейс с комментариями.

## Важно

- Не удаляй `export` — иначе страницы не увидят данные.
- После правки не нужно перезапускать сервер — hot-reload подхватит изменения.
- Если хочешь убрать секцию — закомментируй или удали её импорт из соответствующей страницы.
